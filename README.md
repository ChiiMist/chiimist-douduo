# 豆朵 · 拼豆图纸生成器

Next.js + TypeScript + Sharp，本机体验版。需求基线见 [需求文档.md](./需求文档.md)。

## 启动

需要 Node.js 20.9 或更新版本。

```sh
npm install
npm run dev
```

浏览器打开终端显示的 http://127.0.0.1:3000 。图纸生成不需要第三方模型密钥。

```sh
npm run typecheck
npm test
npm run build
```

## 处理方式

当前版本只使用本地/服务端 CV 算法生成图纸，不调用外部 AI API，也不需要第三方模型密钥。

## 数据与限制

221 色数据来自用户提供、经豆包转述的玩家整理文本，存放于 `lib/palette.ts`。非官方认证，仅供本地参考体验。对外发布前需核查原始来源、许可与实物色号对应。

色值仅为屏幕参考，拼豆不同生产批次本身存在轻微色差，显示器也会有色彩偏差，最终以实物色卡为准。

无数据库，不持久化图片或图纸；刷新清空。服务端采用进程内限流，多实例部署需要网关补充。图片限制 10 MB、2000 万像素。分流采用启发式阈值，仍需真实样本标定。界面显示组合处理阶段，不伪造进度百分比。
